# First Encounter Lab

The Lab is the first reusable gameplay tile for Trapstar / First Encounter Game. This repository contains the design, source locks, and setup evidence. Teddy approved M01–M06 for Lab design and governance. A playable Lab requires separate authorization and implementation.

1. Start with the [master design](FIRST_ENCOUNTER_LAB_MASTER_DESIGN.md).
2. Read the [owner approval record](docs/decisions/FIRST_ENCOUNTER_LAB_OWNER_APPROVALS_M01_M06_2026-11-14.md), [decision register](docs/decisions/DECISION_REGISTER.md), and [remaining gates](docs/decisions/OPEN_APPROVALS.md).
3. See the [preflight report](docs/preflight/FIRST_ENCOUNTER_LAB_PREFLIGHT_REPORT.md), [source lock](docs/provenance/SOURCE_LOCK.json), and [setup report](docs/setup/REPOSITORY_SETUP_REPORT.md).
4. The [build checkpoints](docs/architecture/BUILD_CHECKPOINTS.md) define the future entry gate and the evidence needed to advance.

Teddy and Nova review this setup first. A separate owner command must name the reviewed baseline and permitted work before the Lead and seven specialists can start.
